Checkpoint 17

Multiple hosts: saved locally, added by host:port (optional password and TLS), switched with one click. Switching drops every per-host cache (sessions, timelines, checkout, terminals, files, config) and the view. An unreachable host gets a plain offline card; a host saved by address takes the daemon's own name on first connect.

Checkpoint 16

Full sweep: every scenario at desktop (1440), landscape tablet (1024), portrait tablet (768, list as a drawer) and phone (390). Status bar now carries branch, ahead count, diff stat, PR checks, the open session's model and ⌘K.

Checkpoint 15

Motion layer (web): running glyphs breathe; the rail indicator glides between tools (frame caught mid-glide); selection brackets snap in; the working line names what the agent is doing with a shimmer (static amber when it waits on you); running tool cards carry a beam on their top edge; panels enter in 200ms. All of it drops to near-instant under prefers-reduced-motion.

Checkpoint 14

Chat depth: tool calls expand to their real content (diffs, shell output, file reads, search hits); model and mode are live pickers in the composer; J / K walk the session list, A / Esc answer the open session's permission. Bracket shapes now clip only their paint layer, so menus can open out of them.

Checkpoint 13

Every rail tool is now live: Tasks (the session's plan and subagents), Plugins (installed with enable toggles, catalog with install and capability notice), Companion (notebook and a text line). Mock sessions have no plan, so Tasks shows its empty state.

Checkpoint 12
