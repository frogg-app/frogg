Round 4 — Bracket + Rail, every surface

The Bracket + Rail direction extended to the whole product. The rail is now a tool switcher (not project icons); projects move into a scope switcher at the top of the session list. Each tool owns the side panel and the main area. Every menu, setting, modal, toast and state from the content inventory has a place. Each card opens that exact state live; rate and add notes as you go (saved to the server). Round 3 · Open the app

Settings tree (grouped by where it is stored)

  • You · this device: Appearance · Chat & composer · Files, editor & terminal · Keyboard shortcuts · Notifications & inbox · Voice & Companion
  • Agents · host: Providers & models · Accounts · Permission modes · Usage & limits · Context & clean cut · Tools, skills & prompts
  • Host (host switcher): Overview & connections · Devices & access · Security · Automation · Session labels · Terminal profiles · Resources & storage · Daemon & updates
  • Project (project switcher, writes frogg.json): Worktrees · Scripts & services · CI & release streams · Generated text
  • App: Plugins · App updates · About & diagnostics · Developer

Every page header carries a scope badge (This device / devbox · config.json / frogg-app · frogg.json). ⌘K searches settings by keyword.

Where modals live

  • Sessions: New session (⌘N, + in list header), Import (scope menu, session menu), Archive / Rewind / Labels (session and tab menus, row right-click)
  • Composer: model, mode, account, provider, attach and / popovers open upward from their chips
  • Source control: branch switcher (branch card), git actions (⋯), commit options; PRs: merge strategies
  • Hosts: Add a host (+), Pair a device (host header, Settings › Devices), Deploy, Remove (host ⋯)
  • Plugins: consent on Install; Providers: detail and catalog in Settings; Accounts: Add / Move
  • Global: ⌘K palette, ? shortcuts, toasts bottom-right, host banners above the session header

Consolidations from the inventory

  • Pairing: six flows → one. “Add a host” has five methods (offer via QR/link/code, network, SSH, deploy, direct) that all end in one confirm step (fingerprint, role, claim). “Pair a device” shows QR, link and code as one offer.
  • Daemon updates: four paths → one page. Host › Daemon & updates; Frogg picks self-update, desktop bundle or SSH redeploy. Beta daemons move to Developer.
  • Permission modes: one vocabulary. Plan · Ask · Auto-edit · Auto · Unattended, with the provider’s own name shown beside (Bypass / Full Access / Allow All → Unattended).
  • “Session” everywhere. Workspace is gone from copy; worktree is an attribute of a session.
  • Changes + git actions = Source control. One tool; the chat keeps a quick changes drawer.
  • Chats and History are Sessions scopes, not separate screens.
  • Usage in one place. Device meter prefs and host plan usage both live under Usage & limits (tool + settings page).
  • Notifications persist. New Inbox is the record; toasts, OS alerts, push and spoken alerts are deliveries, routed per type.
  • Hidden settings get controls: vim mode, open-in-side-pane, PR open location, port ranges, Jenkins CI.
  • Shortcut fixes: ⌘O labelled “New agent in this session”; split / focus pane on every platform; rail tools get bindings.
  • Developer-only surfaces (release streams, dev builds, beta daemons) appear only with Developer mode on.
