Frogg Next has colour themes, set per device under **Settings → Appearance**. The layout is the
same in every theme; only colours change.

| Theme     | Look                                                                 |
| --------- | -------------------------------------------------------------------- |
| Material  | Neutral graphite surfaces with one calm blue accent. The default.    |
| Blue Tech | The original deep-teal look with cyan glow.                          |

## Pick a theme

1. Open **Settings → Appearance**.
2. Click a theme card. Each card previews the theme's own colours.
3. Click **Apply and reload**. The app reloads in the new theme. **Discard** drops the change.

## Override colours

Under **Colour overrides**, each main colour (backgrounds, text, accent, status colours) has a
field that takes a `#rrggbb` value. An override sits on top of whichever theme is active, and
tints derived from that colour, such as hover and selection washes, follow it. Clear a field or
use its reset button to go back to the theme's value, or **Reset overrides** to clear them all.
Changes apply with **Apply and reload**.

Themes and overrides are stored on the device, so each desktop, browser and phone keeps its own.
